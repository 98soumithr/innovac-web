# innovac-web

Website for Innovac Ceramic Pvt Ltd (innovacceramic.com).

This repo starts as a build kit. Open it in Claude Code and follow `docs/build-plan.md` §2–3, one phase per session.

- `CLAUDE.md` — rules Claude Code follows in every session
- `docs/design-system.md` — the Blue Flame look
- `docs/site-plan.md` — sitemap, page specs, SEO, redirects, content model
- `docs/build-plan.md` — folder structure, phases, and a prompt for each
- `docs/content-checklist.md` — facts and photos Innovac must supply
- `docs/reference/homepage-mockup.html` — the approved homepage reference (open it in a browser)
